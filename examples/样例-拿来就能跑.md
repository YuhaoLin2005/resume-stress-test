# 样例 · 拿来就能跑

> ⚠️ **以下内容完全虚构**，公司、姓名、数字均为编造，与任何真实个人或企业无关。
> 它的作用是让你**不必用自己的简历**就能先跑一遍，看看这套流程问出来的东西长什么样。

用法：把下面两段分别复制给 AI——先给它 JD，再给它简历。或者直接把整个文件丢过去。

这份样例**故意埋了问题**，三个角色都有活干。跑完可以对照
[`case-02-一次真跑跑出了什么.md`](case-02-一次真跑跑出了什么.md) §八 的虚构样本，
看同样的缺口在流程里长什么样。

---

## 一、JD（复制这段）

```
岗位：数据分析实习生
公司：星野科技（虚构）

工作内容：
1. 负责业务数据的日常提取、清洗与看板维护；
2. 配合业务方做专题分析，输出结论与建议；
3. 参与指标口径梳理与文档沉淀。

要求：
- 本科及以上在读，每周到岗 4 天以上，可连续实习 6 个月；
- 熟练使用 SQL，能用 Python 做数据处理；
- 熟悉至少一种可视化工具（Tableau / Power BI / 帆软等）；
- 熟悉 Ubuntu/Linux 基本操作者优先；
- 有 A/B 实验或用户留存分析经验者优先。
```

## 三、跑完之后

你大概会看到三个角色分别咬住不同的地方——比如：

- **角色1** 会问「30% 的口径」「『独立完成』的边界」；
- **角色2** 会问「JD 要 A/B 经验，你哪一条对应得上」；
- **角色3** 会说「个人简介那句没有任何信息量」。

**它们问的是同一份简历，但问题几乎不重叠。** 这就是三层不交叉就看不见的那部分。
